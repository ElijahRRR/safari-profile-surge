# Badge

一两个字的状态或分类标签，胶囊形，放在表格单元格、标题旁。

- **变体**：`badge-primary`（品牌/渠道，如 WFS）、`badge-success`（已完成、已发货）、`badge-warning`（待处理）、`badge-danger`（失败、已取消）、`badge-gray`（草稿、未启用）、`badge-purple`（促销等特殊分类）。
- **规格**：12px 字重 500、`radius-full`、`space-2.5` × `space-0.5`；浅色 100 阶底 + 700 阶字，暗色 900 阶 30% 底 + 400 阶字。可在文字前放 12px 图标。
- **使用方提供**：文案和语义对应的变体。颜色必须与含义一致，不要为了好看换色。
